## 한 줄 요약
워크샵용 텔레스트레이션. 각자 폰으로 제시어(음식·장보기 상품)를 그리고, 스케치북이 돌며
추측 → 다시 그리기를 반복한다. 다 돌면 한 권씩 공개하며 "망작 표"(1인 3표)를 주고, 표를 가장 많이
받은 사람이 바베큐 뒷정리.

## 동작하는 것 (Done)
- 화면: `src/game.html` + `src/game.css` + `src/game.ts` — App.tsx 는 HTML 을 붙이고 `initGame()` 만 호출.
- 1.5초 `GET /state` 폴링(그림 내용 없음). 칸 시간표는 서버 시계 오프셋으로 계산해 자동 진행
  (그리기 dSec → 3초 넘김 → 추측 gSec → …). 칸 내용은 `/task`, 공개 스케치북은 `/book` 으로 따로 받는다.
- 그림판: canvas 480x480, 색 7 + 지우개, 굵기 3, 되돌리기, 전부 지우기. JPEG dataURL 로 제출.
  마감 0.8초 전 자동 제출(안 그렸으면 빈 그림, 추측이 비었으면 "모르겠어요…").
- 공개: 진행자가 이전/다음으로 넘기면 모두의 화면이 따라간다. 지난 스케치북 다시 보기 가능.
- "나" 구분은 브라우저 랜덤 키(localStorage `telestration-key`). 진행자는 처음 "내가 진행자 하기"를 누른 브라우저.

- 연습용 가상 참가자: 진행자 메뉴 → 로비에서 추가. 진행자 화면이 켜져 있는 동안만 움직임.
- 테마: 민트·블랙(game.css :root 토큰).
- 제시어 난이도: 새 판 열기에서 하·중·상 선택(기본 하).

- 빠른 진행(2026-10-14 개편): 모두 내면 바로 다음 칸 / 투표는 각자 폰에서 동시에(요약 카드 그리드) / 투표 시간 끝나면 자동 결과.
- 가상 참가자 그림·추측: `src/bots.ts`.
